# 🛒 FreshMart Super Market Website

## 📌 Project Overview

FreshMart Super Market Website is a modern and responsive static website developed using **HTML5** and **CSS3**. The website is designed to provide customers with a clean and user-friendly interface for exploring supermarket products, categories, special offers, and contact information.

This project demonstrates front-end web development skills by creating an attractive shopping website layout without using JavaScript or any external frameworks.

---

# 🎯 Objectives

* Design a professional supermarket website.
* Create a responsive and attractive user interface.
* Improve user experience with a simple navigation system.
* Display supermarket products and categories in an organized manner.
* Practice HTML and CSS concepts.

# 🚀 How to Run the Project

1. Download or clone the project.
2. Open the project folder.
3. Open **index.html** in any modern web browser.
4. The website will load successfully.

No installation or server is required.
